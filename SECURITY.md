# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/foigent/integration-control/security/advisories/new)
for sensitive reports. This public repository has private vulnerability
reporting enabled and verified on 2026-10-11.

Do not include vulnerabilities, credentials, customer data or runtime dumps in
public issues. If the private form is unavailable, request a confidential
channel without posting sensitive details. Ordinary questions belong in
[Issues](https://github.com/foigent/integration-control/issues); conduct concerns use the
contact in the [Code of Conduct](CODE_OF_CONDUCT.md).

Report the affected commit or release, expected boundary, observed behavior and
a minimal reproduction with synthetic files. Relevant concerns include strict
parsing, canonicalization, identity/digest verification, conformance gaps and
release verification. A successful test does not authorize product operations.

No security support window, response-time SLA or bounty is established by this
source publication. Immutable historical releases are preserved; fixes require
an explicitly reviewed successor and consumer adoption.
